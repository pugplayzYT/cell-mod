# Intertnet Cellular Network

A Minecraft 1.21.1 mod for NeoForge. Buy a phone and SIM at an Open World cell tower, build a private network, text other players, or use your phone to order meals and book rides.

Public towers, restaurants, rideshare centers, and emergency stations generate in new chunks. The phone's free SOS calls dispatch medics or police over cell or satellite reception. Intertnet replaces normal player chat with phone messaging.

Open World tower stalls sell removable phone antennas that provide Global Satellite reception across the Overworld. The phone switches over automatically when regular reception drops and there is enough open sky.

## Build

Install JDK 21 and run the included Gradle wrapper.

- Windows `.\gradlew.bat build`
- Linux or macOS `./gradlew build`

The build creates `build/libs/intertnet-1.0.6.jar`. Copy it into the mods folder of a Minecraft 1.21.1 NeoForge instance. For multiplayer, install the same build on the server and clients.
